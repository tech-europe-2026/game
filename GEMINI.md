## Itch.io Publishing Checklist
- [ ] Complete the core gameplay loop.
- [ ] Export the game build for the target platform.
- [ ] Create a new project page on itch.io.
- [ ] Upload the game files (e.g., `.zip` for HTML5 web games).
- [ ] Upload a cover image and screenshots.
- [ ] Add a short description and tags.
- [ ] Set pricing (e.g., Free / "Name your own price").
- [ ] Change status to Public and publish!

## Agent Rules
- **Environment Variables**: Whenever a new environment variable or key is added to or removed from the `.env` file, you MUST automatically update `.env.example` to match the new structure (without exposing the actual secret values).
